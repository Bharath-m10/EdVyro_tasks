# Responsive Internship Board

An accessible internship listing interface built entirely with semantic HTML, CSS, and vanilla JavaScript without any external frameworks.

## Features
* **Semantic HTML:** Structured page layout with clear, accessible elements.
* **Responsive Design:** Adapts smoothly to mobile, tablet, and desktop screens using CSS Grid.
* **Dynamic Filtering:** Search for internships by role or company, and filter results by domain.
* **Accessibility:** Includes hidden form labels and supports full keyboard navigation.
